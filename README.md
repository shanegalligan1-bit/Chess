# Chess Castle

A friendly chess game for young beginners (built for ages 5–8). Open `index.html` in any browser: no install, works on a tablet, laptop, or phone.

| Mode | What it teaches |
|---|---|
| **Learn the Pieces** | Rook → Bishop → Queen → King → Knight → Pawn, 3 star-collecting levels each, then Check and Checkmate puzzles |
| **Play the Robot** | Full game vs Sleepy (random), Silly (greedy), or Clever (looks ahead) robot |
| **Play a Grown-up** | Two players on one screen |

**Kid-friendly helpers**
- Hoot the owl coaches every move and can **read everything aloud** (for early readers).
- Tap a piece to see its moves: **green dot = safe**, **orange dot = it could be captured there**.
- Pieces in danger pulse with a **red circle**; risky moves ask "are you sure?" first.
- **Take back**, **Hint**, piece point values, confetti on wins. Progress and name are saved in the browser.

Run the engine and lesson tests with `node tests/engine.test.js`.
